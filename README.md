# OnlyProtein 💪

A React Native food ordering app focused on high-protein meals.

## Features

* React Navigation setup
* Stack Navigation
* Drawer Navigation
* Bottom Tab Navigation
* Passing data between screens using navigation params
* Dynamic food listing
* Order screen with selected item details
* Custom tab icons using Ionicons
* Basic error handling

## Navigation Flow

Landing Screen
↓
Drawer Navigation
↓
Bottom Tabs
├── Home
└── Orders

Additional screens can be added through the Drawer menu.

## Tech Stack

* React Native
* Expo
* React Navigation
* Ionicons
* TypeScript

## Screens

### Landing Screen

Entry point of the application.

### Home Screen

Displays available high-protein meals.

### Order Screen

Shows selected meal details and order information.

```bash
bun install

```
